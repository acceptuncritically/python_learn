扫地机器人维护保养指南

一、日常维护
1. 每次清扫后清空尘盒，养宠家庭建议每次或每天清理。
2. 检查主刷、边刷和轮子是否缠绕毛发，及时清理。
3. 拖地后倒空水箱，清洗拖布并晾干，避免异味。
4. 擦拭充电触点，保持干燥，确保回充稳定。
5. 收起地面电线、数据线、窗帘绳和拖鞋，减少卡困。

二、每周维护
1. 清洗或擦拭拖布，清洗基站清洗盘和吸污口。
2. 用干软布擦拭激光头、避障镜头、悬崖传感器和回充触点。
3. 检查滤网灰尘，轻拍清理；可水洗滤网必须彻底晾干。
4. 检查边刷是否外翻、主刷是否磨损、轮子是否回弹正常。
5. 自动集尘基站检查尘袋容量和进尘口是否堵塞。

三、每月维护
1. 深度清洁尘盒、滤网仓、主刷仓和吸口风道。
2. 清洁基站底座、水箱、清洗槽和污水通道，防止水垢和异味。
3. 检查电池续航是否明显下降，检查充电座电源线。
4. 检查APP固件升级和地图是否准确，修正房间和禁区。
5. 长期潮湿地区注意晾干拖布和基站，防止霉菌。

四、每季度维护
1. 检查主刷、边刷、滤网、拖布和集尘袋，按磨损更换。
2. 清洁轮轴、万向轮和驱动轮周围毛发。
3. 检查充电座位置是否被移动，地图是否需要重建。
4. 检查水箱密封圈、出水口和管路是否老化漏水。
5. 长期不用前充满或保持约50%电量，干燥存放并定期补电。

五、耗材参考更换周期
1. 滤网：约1至3个月，或吸力下降、破损时更换。
2. 主刷：约3至12个月，或刷毛变形、磨损严重时更换。
3. 边刷：约3至6个月，或刷毛外翻、断裂时更换。
4. 拖布：约1至3个月，或变硬、发黑、异味时更换。
5. 集尘袋：约20至60天，或装满、异味、破损时更换。
6. 电池：约2至3年，或续航明显下降时考虑官方更换。
7. 清洁剂：只用厂商允许的专用清洁剂，禁止随意混合使用。

六、注意事项
1. 清洗任何电子部件前先关机断电，避免水进入主板和电池。
2. 不要用热水浸泡滤网、拖布以外的电子部件。
3. 不要用腐蚀性清洁剂擦拭激光头和传感器。
4. 耗材周期因品牌、户型、宠物和使用频率不同，以说明书为准。
5. 出现漏水、异味、异常噪音、充电发热或反复卡困时，先停用并联系售后
