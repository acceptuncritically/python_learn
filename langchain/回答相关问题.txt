提示词模板的区别
标准案：PromptTemplate 用于纯文本补全模型（输入输出都是字符串）；ChatPromptTemplate 用于对话模型（输入是消息列表 List[BaseMessage]）。构建多轮对话必须用 ChatPromptTemplate。
2. Few-Shot 提示词
标准答案：使用 FewShotPromptTemplate。核心包含：examples（示例字典列表）、example_prompt（每个示例的格式模板）、prefix（前缀）、suffix（最终用户的问题后缀）。
3. JSON 解析器处理 Markdown
标准答案：JsonOutputParser 不能完美处理带 Markdown 的代码块。解决方案：① 在 Prompt 中严格要求模型“仅输出纯 JSON，不要包含 ```json 等 Markdown 标记”；② 使用 RegexParser 或 Python 原生正则替换掉无关字符；③ 使用 OutputFixingParser（调用第二次 LLM 修复错误）。
4. LCEL 管道符 | 的作用
标准答案：| 是 LCEL 的语法糖。它将前一个 Runnable 的输出作为后一个 Runnable 的输入。底层通过重写 __or__ 方法，实现了链式调用和自动数据流传递。
5. 自定义函数加入链
标准答案：使用 RunnableLambda 包装普通函数（RunnableLambda(func)），即可让该函数拥有 invoke、stream 等方法并接入 LCEL 链中。如果是多个输入合并，可以用 RunnablePassthrough.assign。
6. 流式输出
标准答案：在 LLM 初始化时设置 streaming=True。调用链时使用 .stream(input)，然后通过 for chunk in chain.stream(): print(chunk, end="", flush=True) 实现打字机效果。
7. 临时记忆与长期记忆
标准答案：临时记忆（如 BufferMemory）存在于内存中，会话结束即销毁；长期记忆需要持久化（如存 Redis/DB），并且对于超长记忆，通常采用摘要记忆（Summary）或向量检索记忆（存历史对话的向量，按需召回）。
8. 复杂 PDF 处理
标准答案：PyPDFLoader 不够用。处理带表格和图片的 PDF，建议用 UnstructuredPDFLoader（支持结构化提取），或先用 PyMuPDF 提取图片，结合 OCR 技术（如 RapidOCR / Tesseract）识别文字，再喂给大模型。
9. 余弦相似度
标准答案：衡量两个向量在方向上的夹角，夹角越小（余弦值越接近 1），代表语义越相似。
10. RAG 全流程与 Token
标准答案：流程：文档加载 -> 文本分割 -> 向量化(Embedding) -> 存入向量库 -> 用户提问向量化 -> 相似度检索（Top-K） -> 组装 Prompt -> 送 LLM 生成。最耗 Token 的是“组装 Prompt 后送给 LLM”这一步（因为包含了检索到的庞大上下文）。Embedding 模型直接决定了检索的召回质量。
11. 综合伪代码逻辑
